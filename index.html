Classes 1–4 —the first complete build

Anatomy of a first invention.

A light sensor reads the room, the ESP32 decides, an LED responds — the whole IoT loop, wired by an eight-year-old.

// the if-then rule, class 3
if (lightLevel < darkThreshold) {
  digitalWrite(LED, HIGH); // it's dark → glow
} else {
  digitalWrite(LED, LOW);
}
